# Evidências técnicas reais — checklist

Salve aqui **apenas capturas reais** obtidas durante uma execução validada. Não inclua chaves, IDs sensíveis, assinaturas institucionais ou dados pessoais.

- [ ] EcoPredictor: execução do AutoML (sem segredos), métricas obtidas, teste HTTP do endpoint e resultado real exibido no frontend.
- [ ] OCR: resultado de uma imagem de teste sintética, URL de recurso ocultada, saída JSON e comparação com texto esperado.
- [ ] QMax: deployment do modelo (sem chave), requisição REST de verdade e retorno exibido no chat.

**Não use `docs/mockups/` como prova de execução dos serviços.**
